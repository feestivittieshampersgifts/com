# Feestivities Hampers & Gifts

A responsive three-page brand website rebuilt from the supplied structured-site ZIP. Its visual direction is an editorial gift atelier with restrained liquid-glass surfaces, real product photography, warm paper tones and a deep berry accent.

## Pages

- `index.html` — brand introduction, horizontal/filterable gift edit, occasion discovery and WhatsApp enquiry links.
- `services.html` — hampers, gifts, flower bouquets, souvenirs and the supplied occasion categories.
- `contact.html` — original contact details, social links and a validated enquiry form that opens a prefilled WhatsApp message.

## Images and business information

All website photos are the original photos from the uploaded ZIP and are referenced from project storage. No stock or generated photography is used. The site retains the supplied email, WhatsApp number, and Instagram, Facebook and TikTok links. It does not invent prices, testimonials, delivery promises, locations or addresses. The website has no cart, payment or backend checkout; all enquiries continue in WhatsApp.

## Run locally

Serve this folder with any static HTTP server, for example:

```sh
python3 -m http.server 3000
```

Then open `http://localhost:3000`.
